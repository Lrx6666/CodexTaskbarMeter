# CodexTaskbarMeter# Codex 任务栏用量

双击 `CodexTaskbarMeter.exe` 即可运行。请先在本机 Codex 中登录 ChatGPT。
无需管理员权限，不需要安装 Python、Node.js 或浏览器运行环境。
程序使用 Windows 自带的 .NET Framework 4.8。当前已在 Windows 11 环境编译。

## 显示内容

- 五小时已用百分比和本周已用百分比。
- 两个用量窗口各自的下次重置日期和时间。
- 剩余重置卡数量。
- 鼠标悬停查看完整年月日、星期、剩余百分比和更新时间。

任务栏内的百分比表示已用。完整日期和星期可在悬停信息或右键菜单的用量详情中查看。
重置时间使用 Windows 本地时区。接口没有提供的数据显示为 `--` 或未知，不会补成零。
到达重置时间后显示等待刷新，直到接口确认新数据。

## 调整外观

背景为逐像素透明，文字默认跟随 Windows 任务栏的深浅主题。
默认显示两行。右键可以切换紧凑模式、更改文字颜色和字体大小。
按住文字区域即可左右拖动。右键的位置菜单也可逐步移动或恢复靠左、靠右位置。
默认靠左，并预留天气区域。位置会保存在程序旁边的 `data/settings.json` 中。

本程序以透明小窗口贴在主显示器的水平任务栏上，不会修改或注入 Explorer。
它不为任务栏按钮预留空间。如果与现有图标重叠，拖动到任务栏空白处，或启用紧凑模式。
全屏应用和自动隐藏的任务栏收起时，文字会隐藏。通知区域图标仍可打开菜单。
当前版本只在主任务栏显示，不支持竖直任务栏或为每个显示器分别放置。

## 自动刷新

默认每 5 分钟读取一次，可以改为 1、3、5 或 10 分钟，也可以立即刷新。
只读取官方 `account/rateLimits/read` 接口，后台查询跳过重置卡详情，只读取数量。
读取期间短暂启动本机 `codex app-server`，完成后退出。不会启动模型对话或消耗模型推理额度。
原生界面没有常驻浏览器引擎。实际占用与系统字体、缩放和本机 Codex 版本有关。

断网或读取失败时保留上次成功数据，并标记旧数据。悬停信息显示最后更新时间和失败提示。
首次没有数据时显示未知。如果登录失效，先在 Codex 里重新登录，然后右键立即刷新。
程序会自动找到 Codex 桌面应用内的 `codex.exe`。也可用右键菜单手动选择。

## 启动和退出

右键选择开机启动，会在当前用户的 Windows 启动文件夹中创建快捷方式。
默认不开启。再次点击即可取消。开启后请保留本文件夹的位置。
退出请使用任务栏文字或通知区域图标的右键菜单。
程序退出后可删除整个文件夹。若启用过开机启动，先在菜单中关闭它。

不会兑换或消耗重置卡，也不提供兑换按钮。

已验证实际用量读取，包括五小时窗口、周窗口、重置时间和重置卡数量。
